# Терминал — быстрый старт

Если ты просто хочешь провести занятие и не разбираться в устройстве сайта —
этот файл для тебя. Остальное (как всё устроено, что можно поменять) —
в [README.md](README.md).

## Что нужно заранее

Python на компьютере тьютора. Проверить:

```
python --version
```

Если пишет ошибку — поставь Python с [python.org](https://python.org),
галочка «Add python.exe to PATH» при установке обязательна.

Для занятия по C# нужен ещё .NET SDK — см. ниже. Для занятия по Python
не нужен вообще ничего сверх Python.

## Запуск — одна команда

Дважды кликнуть **`start.bat`**.

Или из терминала:

```
python start.py
```

Один раз при самом первом запуске (нужен интернет на минуту) поставятся
недостающие библиотеки. Дальше — без интернета.

Команда сама:

1. проверит и поставит, чего не хватает;
2. соберёт запасную версию для флешки (на случай, если сеть в классе подведёт);
3. запустит сервер и откроет сайт у тебя в браузере — убедиться, что всё поднялось;
4. напечатает в консоль адреса **крупно**.

Дальше в консоли будет три адреса:

| Адрес | Кому |
|---|---|
| `http://192.168.x.x:8000` | детям — открывают на своих ноутбуках |
| `.../board` | вывести на проектор |
| `.../tutor` | тебе — прогресс группы и кто где застрял |

`/board` и `/tutor` закрыты паролем. По умолчанию **`admin123`**, консоль
про это напоминает. Свой пароль:

```
set TERMINAL_PASSWORD=свой-пароль
python start.py
```

Остановить сервер — `Ctrl+C` в окне консоли, или просто закрыть его.

## Если у детей не открывается

Почти всегда причина одна: в Wi-Fi класса включена **изоляция клиентов**,
и ноутбуки детей не видят машину тьютора вообще. Проверить это можно только
заранее, посреди занятия чинить некогда.

**Проверить за день:** открыть напечатанный адрес с другого ноутбука
в этой же сети.

**Если не открывается:** раздать точку доступа с телефона и подключить
к ней и свой ноутбук, и ноутбуки детей — в личной точке изоляции нет.

**Если и это не вариант:** запасная версия уже готова — команда её собирает
каждый раз сама. Лежит в папке `../terminal-offline/Терминал` рядом
с проектом. Скопируй на флешку, раздай детям, пусть каждый откроет файл
`Терминал.html` на своём ноутбуке. Работает совсем без сети и без сервера,
только занятие по Python — C# в ней нет.

## Занятие по C#

Нужен .NET SDK на машине тьютора. С правами администратора:

```
winget install Microsoft.DotNet.SDK.8
```

Без прав администратора — ставится в свою папку, инсталлятор не нужен:

```
powershell -c "& { iwr https://dot.net/v1/dotnet-install.ps1 -OutFile d.ps1; ./d.ps1 -Channel 8.0 }"
```

Без SDK занятие по Python работает как обычно, а при попытке проверить C#
сайт честно скажет, что компилятора нет. Консоль сообщает, нашла ли SDK,
при каждом запуске.

## Перед занятием — на всякий случай

```
python tools\check_content.py
```

Прогоняет все задачи через эталонные решения. Если после правки условия
или теста что-то разошлось — падает и говорит, что именно, вместо того
чтобы это обнаружил ребёнок посреди занятия.

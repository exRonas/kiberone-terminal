# Терминал — версия для флешки

Запасной вариант на случай, если в классе не получится раздать сайт по адресу.
Самая частая причина — изоляция клиентов в гостевом Wi-Fi: ноутбуки детей
не видят машину тьютора вообще, и настройками сайта это не лечится.

Эта версия не требует ни сервера, ни сети, ни установки. Папку копируют
на ноутбук и открывают файл двойным кликом.

## Как пользоваться

Из корня репозитория:

```
python tools/build_offline.py
```

Папка соберётся рядом с репозиторием, в `../terminal-offline/Терминал` — её
и копируют на флешку целиком.

Пересобрать после правки задач или вёрстки в основном проекте:

```
python tools/build_offline.py
```

Скрипт читает исходники репозитория и ничего в них не меняет. Все замены
при сборке проверяются: если основной проект изменится так, что патч не ляжет,
сборка упадёт с понятным сообщением, а не соберёт молча сломанное.

## Что внутри

Восемь тем, 24 задачи, полная проверка тестами. Python выполняется в самом
браузере через Skulpt.

Задачи зашиты в `content.js`: браузер запрещает читать файлы с диска по
`file://`, поэтому данные должны приехать скриптом, а не через `fetch`.

## Чего здесь нет и почему

**Общей таблицы на проекторе.** Её считает сервер, а сервера в этой версии нет.
Прогресс каждого ребёнка виден у него в шапке страницы; тьютор ходит и смотрит.

**Занятия по C#.** Его проверка требует компилятора на каждом ноутбуке — это
285 МБ и установка SDK на каждую машину, что съест ползанятия. C# работает
только в обычной версии, на машине тьютора.

## Прогресс

Живёт в `localStorage` того браузера, где ребёнок работал. Переживает
перезагрузку страницы и закрытие браузера. Не переносится между ноутбуками
и обнуляется при очистке данных браузера.

## Проверено

- Открытие по `file://` в Chrome: стартовая страница, все восемь тем,
  переход между темами по индикатору курса.
- Запуск примеров теории и проверка задач без всякого сервера.
- Прогресс переживает перезагрузку страницы.
- Все 24 эталонных решения прогнаны внутри собранной версии: 98 тестов,
  ноль провалов.
- Ошибок в консоли нет.

## Отношение к основному проекту

Собранная папка не входит в репозиторий и никогда не должна: она полностью
выводима из `content/python/*.json` и `server/static/*`. Хранить в git имеет
смысл только `tools/build_offline.py` и этот файл.

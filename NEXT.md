## 1. Развернуть на новой машине

```
git clone https://github.com/exRonas/kiberone-terminal.git
cd kiberone-terminal
pip install -r requirements.txt -r requirements-dev.txt
```

Для C# нужен .NET SDK. С правами администратора:

```
winget install Microsoft.DotNet.SDK.8
```

Без прав администратора — в папку пользователя, установщик не нужен:

```
powershell -c "& { iwr https://dot.net/v1/dotnet-install.ps1 -OutFile d.ps1; ./d.ps1 -Channel 8.0 }"
```

Сервер ищет `dotnet` и в `PATH`, и в `%USERPROFILE%\.dotnet`.

**Сразу после установки проверь, что всё живо:**

```
python tools/check_content.py     # должно быть «Всё сошлось: 196 тестов»
python -m pytest tests -q         # должно быть «88 passed»
python server/app.py              # адрес крупно в консоли
```

Если `check_content.py` пишет «.NET SDK не найден» и падает — это не поломка,
а так и задумано: команда не притворяется успешной, когда половина курса
не проверена.

Первый запуск с SDK прогревает компилятор около полминуты. Дальше проверка
задачи укладывается в секунду.

## 3. Что сделать до занятия

**Обязательно:**

1. **Проверить сеть в классе за день.** Открыть адрес сервера с чужого
   ноутбука в той же сети. Во многих гостевых Wi-Fi включена изоляция
   клиентов — тогда дети не увидят машину тьютора вообще, и никакая
   настройка сайта это не лечит. Запасной вариант — точка доступа
   с телефона тьютора.
2. **Прогреть компилятор** перед занятием по C#: просто запустить сервер
   заранее, он сделает это сам и напишет «компилятор готов».
3. **Вычитать теорию глазами.** Тексты карточек написаны мной, а не
   методистом. Формулировки стоит прочитать вслух и поправить под то,
   как вы обычно объясняете. Всё лежит в `content/*/**.json`, поле `text`.

**Желательно:**

4. Прогнать одну тему целиком за ребёнка: открыть, решить три задачи,
   взять подсказку, посмотреть, что попало в таблицу.
5. Проверить, как читается таблица с задних парт на вашем проекторе.
   Размеры подобраны под 1920×1080; если проектор 1280×720, шрифт
   уменьшается автоматически, но лучше посмотреть заранее.

## 4. Один вопрос, который я решил за вас — и его легко переиграть

В задании написано: «каждая подсказка стоит балл» и «взятая подсказка
снимает балл, но тему не блокирует».

Взятые подсказки считаются и хранятся, но **на таблице для проектора
баллов нет** — там только число решённых задач. Причина: рядом сказано,
что таблица считает прогресс, а не победу, и что крупных номеров мест
быть не должно. Колонка «баллы = решено минус подсказки» тянет обратно
к соревнованию.

Сейчас подсказки видит ребёнок у себя («взято 2 из 3», и в штампе после
сдачи) и тьютор на своей странице.

**Если нужна колонка с баллами на проекторе:** данные уже есть, поле
`hints` приходит в `/api/board`. Добавить в `server/static/board.js`
в функции `render` ещё одну колонку и поправить `grid-template-columns`
у `.board-legend, .brow` в `style.css`.

## 5. Грабли, на которые я уже наступил

**Skulpt — не CPython.** У него `"м".isalpha()` возвращает `False`:
эти методы работают только с латиницей. Курс написан по-русски, поэтому
решение на `isalpha()` спокойно проходит проверку на компьютере и молча
врёт в браузере у ребёнка. Поймано на задаче `dicts-1`.

`check_content.py` теперь ругается на `isalpha`, `isdigit`, `isupper`,
`islower`, `isspace`, `isalnum` в решениях и подсказках. Если добавляете
задачу с русским текстом — не опирайтесь на эти методы.

**CPython проходит — Skulpt не значит.** `check_content.py` гоняет решения
обычным Python. Это ловит 95% ошибок, но не такие, как выше. Если задача
работает с русским текстом, проверьте её руками в браузере.

**Ошибки компилятора C# и номера строк.** Заготовка с вызовами тестов
приписывается **после** кода ребёнка, перед его последней фигурной скобкой.
Поэтому его строки не сдвигаются. Если будете менять `build_source`
в `server/runner_csharp.py` — не вставляйте ничего выше кода ребёнка,
иначе номера строк поедут и вся польза пропадёт. Есть тест, который
это сторожит: `test_csharp_source_keeps_student_line_numbers`.

**Атрибут `hidden` и CSS.** Дважды напоролся: правило вида
`display: flex` перебивает `hidden`, и элемент показывается, когда
не должен. Если добавляете скрываемый блок — рядом нужен
`.класс[hidden] { display: none; }`.

**Автозакрытие скобок в редакторе снято намеренно.** Оно убирает ровно
ту ошибку `CS1513: } expected`, которую теория C# учит читать.
Не возвращайте.

## 6. Как добавить или изменить задачу

Всё в JSON, в коде ничего не зашито.

1. Открыть `content/python/<тема>.json`, дописать задачу в `tasks`.
2. Скопировать её в `content/csharp/<тема>.json` **с тем же `id`**,
   заменить `starter`, `solution`, `entry` и добавить `signature`.
3. Запустить `python tools/check_content.py`.

Что проверяется автоматически:

- эталонка проходит все свои тесты (на обоих языках);
- ровно один скрытый тест на задачу;
- две-три подсказки;
- id уникальны;
- **задачи на двух языках совпадают один в один**: id, заголовки,
  аргументы и ожидания тестов. Разойдутся — проверка упадёт.

`signature` нужен только для C#: по нему генерируются литералы аргументов.
Поддерживаются `int`, `long`, `double`, `bool`, `string`, `int[]`,
`string[]`, `dict` (это `Dictionary<string, int>`).

Поле `must_call` — если задача обязана вызывать свою же функцию
(как `primes_up_to` вызывает `is_prime`). Проверяется по исходнику
и показывается отдельной строкой в списке тестов.

## 8. Что осталось непроверенным

Честно, чтобы не было сюрпризов.

**Настоящая нагрузка.** Всё гонялось на одной машине. Если двенадцать
детей нажмут «Проверить» на C# одновременно, четыре компиляции пойдут
параллельно (`POOL_SIZE = 4` в `runner_csharp.py`), остальные подождут.
При сборке около секунды худший случай — секунды три. Некритично,
но живьём на группе не проверялось. Если окажется медленно — поднять
`POOL_SIZE`, но не выше числа ядер.

**Разные браузеры.** Проверялось в Chrome. Skulpt и CodeMirror 5 старые
и всеядные, проблем не ожидается, но если в классе Firefox или Edge —
откройте одну тему заранее.

**Подделка результата.** Проверка Python идёт в браузере, поэтому
через консоль можно отправить фальшивый результат. Это осознанный
размен на работу без сервера и мгновенный отклик.
